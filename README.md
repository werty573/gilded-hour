# Gilded Hour: concept website

A single-page site for **Gilded Hour**, a fictional wedding and event planner for Trinidad and Tobago.

Concept build by **Portside Digital**: websites that work. Gilded Hour is not a real business.

**Look:** Cormorant Garamond + Manrope, cobalt on off-white.

**Scroll animation** (GSAP + ScrollTrigger, switched off for people who prefer reduced motion):
- Hero photo opens from a window to full-bleed while the type turns white
- Statement that lights up word by word
- Expanding service strips
- Planning path that draws itself
- Parallax gallery columns
- Inquiry form

Forms validate and show a success state, but don't send anywhere. On a client build they'd go to the owner's WhatsApp.

Photos: [Unsplash](https://unsplash.com) (Unsplash License).

Open `index.html` in a browser. There's no build step.
